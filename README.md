# FinTrust Digital Bank Project

## What is this project?

FinTrust is an ideal digital bank for this project. My job is to turn its customer and transaction data into clear insights that 
managers can use to make decisions. All the data is synthetic for learning.

## Week 1: Plan

- Understood the business problem and the data
- Chose the questions to answer and the KPIs to track
- Sketched what the dashboard would look like

## Week 2: Do the analysis

- Cleaned and checked the data in Excel
- Answered business questions with SQL
- Explored patterns and made charts in Python
- Built the first Power BI dashboard

## Week 3: Improve and check

- Fix the problems in the Week 2 dashboard
- Do deeper SQL and Python analysis
- Finish the dashboard with trends, slicers and risk review
- Check that my findings are correct
- Write 5 recommendations for management
